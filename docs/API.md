# Libraro API Reference

Source-of-truth reference for every endpoint under `routes/api/v1.php` (mounted at `/api/v1/*`) plus the two top-level routes in `routes/api.php`. Generated by reading each controller's actual validation rules and response construction directly — this codebase has no OpenAPI/Resource layer, so the controller code *is* the contract.

**Keep this in sync.** Any change to a route, its controller's validation rules, or its response structure must update the matching section below in the same PR. See the "API documentation" note in `CLAUDE.md`.

## Conventions

- All paths are relative to `/api/v1/` unless stated otherwise.
- **Auth** describes the route's middleware group. `library_api` guard = `Authorization: Bearer <token>` header (Sanctum), issued by `POST library/login`. `api_key` = a shared app API key header, required on every route in this file. `throttle:60,1` = 60 requests/minute.
- Standard response envelope is `{ status: boolean, message?: string, data?: ... }`, but each controller builds it by hand — always check the per-endpoint table rather than assuming the envelope is uniform.
- **Type** is inferred from the Laravel validation rule (request side) or the literal value being assigned in the controller (response side) — not from a database schema, since none is authoritative here.
- `data.field` = nested object key. `data[].field` = array of objects, each with that key.
- Two independent, unsynchronized **Expense** endpoint sets exist (`MasterController` at `/expense/*` and `LibraryController` at `/library/expense/*`) — see the note in each section.

**Controller:** `LibraryController@guidelines`

**Request payload**
| Field | Type | Required | Notes |
|---|---|---|---|
| guideline_type | string | No | nullable, max:255; when given, filters rows to that type only |
| language | string | No | nullable, one of `en`, `hi`; defaults to `en` |

**Response**
| Field | Type | Notes |
|---|---|---|
| status | boolean | |
| message | string | |
| data | array | `[{ title, description }, ...]` — when `language=hi`, `title`/`description` come from `hindi_question`/`hindi_answer` (falling back to `question`/`answer` if the Hindi column is empty for that row); otherwise from `question`/`answer`. Empty array `[]` if no rows match |
