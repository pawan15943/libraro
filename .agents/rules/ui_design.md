# Workspace Rule: Navy Blue Primary Color & UI Layout Format

## 🎨 Primary Color Directive
- **ALWAYS use Navy Blue (`#18225f`)** for all primary buttons, headers, active navigation, active pagination items, icons, and primary UI highlights.
- **DO NOT use standard blue (`#007bff`, `#0d6efd`)**.

## 📐 Uniform UI Layout Structure
- **Heading Block**: `<div class="heading-list py-4 d-flex justify-content-between align-items-center"><h4 class="mb-0 fw-bold" style="color: #18225f;">...</h4><a class="btn btn-primary button w-15">...</a></div>`
- **Table Responsive**: `<div class="table-responsive mb-4"><table class="table text-center" id="datatable">...</table></div>`
- **Action Icons**: `<ul class="actionalbls"><li><a href="..."><i class="fas fa-edit"></i></a></li><li><a href="..."><i class="fas fa-trash"></i></a></li></ul>`
